# 🛍️ Mercattô — Marketplace

**Compre, venda e descubra novas oportunidades em um só lugar!**

O Mercattô é uma plataforma de marketplace desenvolvida com o objetivo de conectar compradores e vendedores em um ambiente digital simples, intuitivo e acessível.

A plataforma permite que usuários encontrem produtos de diferentes categorias, enquanto vendedores podem anunciar seus produtos por meio de planos de assinatura mensal.

## 📌 Sobre o projeto

O Mercattô foi desenvolvido como projeto acadêmico do curso de Engenharia de Software, buscando aplicar conceitos de desenvolvimento web, design de interfaces e experiência do usuário.

A proposta é oferecer uma experiência de compra e venda semelhante à dos grandes marketplaces brasileiros, com identidade visual própria e um modelo de monetização baseado em mensalidades para vendedores.

## ✨ Funcionalidades

### 🛒 Para compradores
- Navegação por diferentes categorias.
- Visualização de produtos.
- Pesquisa de produtos.
- Interface intuitiva para encontrar ofertas.
- Experiência de compra simplificada.

### 🏪 Para vendedores
- Possibilidade de anunciar produtos.
- Planos de assinatura mensal.
- Diferentes possibilidades de utilização da plataforma conforme o plano contratado.

## 💳 Modelo de negócio

O Mercattô utiliza um modelo de assinatura mensal para vendedores.

A proposta é disponibilizar diferentes planos, permitindo que vendedores escolham a opção mais adequada às suas necessidades e objetivos comerciais.

🛠️ Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Bootstrap

## 🚀 Como executar o projeto

1. Clone o repositório:

2. Abra a pasta do projeto no Visual Studio Code.
3. Instale a extensão Live Server, caso ainda não possua.
4. Clique com o botão direito no arquivo `index.html`.
5. Selecione **Open with Live Server**.
